Everything in S that is not in A = {copper, sodium, zinc}.

PART B

Everything in A, in C, or in both.
= {copper, sodium, zinc, oxygen}
PART C
(A ∩ B') ∪ C'
A ∩ B' = {copper, zinc}. C' = everything except oxygen.
The union is just C'.
= {copper, sodium, nitrogen, potassium, uranium, zinc}
PART D
B' ∩ C'
B' = {copper, uranium, oxygen, zinc}. Now remove oxygen (not in C').
= {copper, uranium, zinc}
PART E
A ∩ B ∩ C
A ∩ B = {sodium}, but sodium is not in C.
= ∅ (the empty set)
PART F
(A' ∪ B') ∩ (A' ∩ C)
A' ∩ C = {oxygen}, and oxygen is also in A' ∪ B'.
= {oxygen}
ALL ANSWERS
a. A' = {nitrogen, potassium, uranium, oxygen}
b. A ∪ C = {copper, sodium, zinc, oxygen}
c. (A ∩ B') ∪ C' = {copper, sodium, nitrogen, potassium, uranium, zinc}
d. B' ∩ C' = {copper, uranium, zinc}
e. A ∩ B ∩ C = ∅ (the empty set)
f. (A' ∪ B') ∩ (A' ∩ C) = {oxygen}
