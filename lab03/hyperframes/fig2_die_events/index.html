Roll one die
Sample space S = {1, 2, 3, 4, 5, 6}
blue bar: in A
gold bar: in B
A ∩ B
A = even = {2, 4, 6}
B = greater than 3 = {4, 5, 6}
A ∩ B = {4, 6}
joint event: even AND greater than 3
A′ = {1, 3, 5}
complement: every outcome NOT in A
An event is just a set of outcomes, so we can combine events like sets.
