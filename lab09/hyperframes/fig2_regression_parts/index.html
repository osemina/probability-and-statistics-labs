The parts of the model
● observed data points (xᵢ, yᵢ)
━ the regression line: the value of Y we expect for each X
● β₀: the value of Y on the line when X = 0
◢ β₁: how much Y changes when X increases by 1 unit
● predicted value on the line
● observed value yᵢ
┃ εᵢ = observed − predicted: the random error
